# TinyPAD - source code and run records

Paper: "A Multimodal TinyML and Edge-AI Framework for Continuous Health Anomaly Detection Using Wearable IoT Sensor Networks"
Repository: https://github.com/vengicse/TinyPAD

Folders
- code/                     data preparation, TinyPAD + 6 baselines (healthlib.py), experiment runner (run_health.py, run_all.sh), validation-only design selection (dev_select*.py), analysis, Fig. 1  (see code/README.md)
- manuscript/               markdown sources + make_doc.py, which regenerates the Word file from paper_assets/summary.json and the run records
- paper_assets/             Figures 1-9 and summary.json with every number reported in the paper
- refs/                     Crossref-verified reference metadata
- runpod_results/results/   raw per-run JSON records of the reported RunPod runs (main, ablation, design selection, latency), logs and code SHA-256 hashes
- data/                     dataset metadata (the .npz arrays are regenerated by code/prepare_health.py from the public WESAD and MIT-BIH data)

Quick start
  pip install -r code/requirements.txt
  cd code && bash run_all.sh
  python analyze_health.py --results ../runpod_results/results --data ../data --out ../paper_assets
  cd ../manuscript && python make_doc.py
